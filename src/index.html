A SMALL, HONEST TOOL

从浏览器导出，
到清晰的排查材料。

1. 获取 HAR

在 Chrome 或 Edge 开发者工具中打开 Network，复现问题，然后导出 HAR。浏览器的默认脱敏可移除部分凭据，但不保证正文、参数与业务数据均已隐藏。

2. 本地处理与预览

导入文件，补充你知道的客户名、项目名等替换词，生成报告。先查看脱敏预览；规则变化后需要重新生成。

3. 分享需要的材料

脱敏 HAR 保留请求顺序、地址、状态与耗时。Markdown 汇总异常与慢请求，AI 分析材料额外附带区分事实和假设的提示词。

明确的边界

自动脱敏不等于彻底匿名化。域名、路径中的普通文字、请求时间和业务模式仍可能敏感。额外替换词采用区分大小写的字面匹配。

此工具不执行请求、不推断已移除的正文、不判断根因，也不保证修复问题。无响应可能是取消、网络失败或其他原因。

页面不保存历史、不使用 Cookie 或浏览器持久存储、不加载第三方字体与分析脚本。离开或清除后，内容不再由页面保存。

文件限制

最大 20 MiB、20,000 条请求；超过限制请先在浏览器筛选。支持有效的 HAR 1.2 JSON。文件正文始终移除。

BUILD → OBSERVE → DECIDE

先验证使用价值，
再决定是否商业化。

为什么做这个

分享网络故障时，用户需要兼顾信息保护和可排查性。这个实验把本地脱敏、请求线索和报告整理放到一个页面。

Chrome 已有基础脱敏，Google 也有开源 HAR Sanitizer；我们验证的是工作流便利性，不声称市场空白或已有付费需求。

如何验证

  1. 用虚构样本展示完整任务。
  2. 邀请目标用户尝试自己的获授权样本。
  3. 记录是否独立完成、是否复用，以及现有工具哪里更好。
  4. 有重复使用后，再验证批量处理、对比和模板是否值得付费。
